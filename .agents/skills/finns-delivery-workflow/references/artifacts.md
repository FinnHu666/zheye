# AI 工作产物保存与交接

## 1. 保存什么、放在哪里

| 类型 | 保存内容与位置 | 规则 |
| --- | --- | --- |
| 需求/计划 | 已确认意图、分点功能、范围、验收、待决；现有权威文档或迭代 PLAN.md | 保留基线，增量记录；不把远程需求正文镜像到仓库 |
| 决定/变更 | DECISIONS.md：决定、备选、简要依据、影响、来源、状态与修订 | 保存可审阅结论，不记录模型隐藏推理或私人聊天逐字稿 |
| 原型/概设/详设/契约 | 既有文档或迭代目录，代码原型使用现有栈 | 写清模拟/实际、版本及确认状态；不能用实现后的截图倒填“原型已确认” |
| 测试/验收 | VALIDATION.md：命令、真实退出码、版本/环境、场景、通过/失败/未验、证据路径 | 不隐去失败，不把模拟或历史证据写成本轮真实验收 |
| 日志/截图/响应/临时包 | 已忽略的 target/<明确迭代目录>/，大包/备份沿用 data/ 的实际约定 | 先核对 .gitignore；仅保存必要脱敏证据，重要文件记录 SHA256 |
| 索引/交接 | ARTIFACTS.md 与 docs/AI_HANDOFF.md，链接权威文件并写下一步 | 不为归档批量重命名、搬走或删除历史资料 |
| Plane 回执 | PLANE_SYNC.md：对象 ID、差异、逐项确认来源、调用与回读结果 | 不保存完整工具响应，远程正文/账号令牌不进仓库 |

AI 过程文件指可复用的产物及证据；不是把对话、下载缓存、node_modules、编译输出或隐私资料全部提交。工具/运行时遵守 D:/E: 规则，skill 不授权安装到 C:。

## 2. 索引最低字段

每个必要产物登记：需求/阶段、用途、路径、修订/状态、产生日期、是否本轮生成/历史引用、敏感性、保存方式、相关确认/验证。重要不可变文件加 SHA256，索引文件自身不作循环哈希。

校验索引中的文件实际存在；未来产物写“待制作”而非伪造链接。哈希只证明对应内容快照，不证明质量或用户确认。更新可变文档后重算受影响哈希；已发布基线保留原快照。

## 3. 敏感数据和可复现性

不把 API Key、加密主密钥、密码、Session、Cookie、OAuth、授权头或未脱敏个人原文写入需求、日志、截图、测试报告、Plane 或 Git。命令使用环境变量引用；删除秘密后再保存，不能只是声明“稍后脱敏”。不能把含密钥的原始响应当成归档必要性。

测试素材优先固定非敏感资料。记录环境/代码版本及命令，不复制完整环境变量表。人工验收截图确认个人信息脱敏；备份和密钥分别按现有受控位置保管，文档只写恢复所需配置名称及步骤。

## 4. 每轮收尾

1. 区分本轮产物、权威基线、历史参考和可重建临时输出。
2. 将零散但有用的技术结论归入已有权威文档，避免相互矛盾；决定及未决进入日志。
3. 更新索引与交接，标注日志/截图等忽略目录可能被清理。重要证据按用户已授权位置保存审阅包及校验清单；若无持久位置，明确证据寿命限制，不声称永久留存。
4. 检查链接、状态、版本与敏感内容；记录未执行的构建/浏览器/数据库/模型检查。
5. 清理或移动既有文件需要适用的用户授权；本 skill 不授权自动删除历史文件、改写记忆目录或上传云盘。

归档记录应让下一位 AI 可以继续，不要求复盘完整聊天。保留失败原因、已尝试方法的结论及下一步，避免重复消耗时间/收费调用；不保存冗长内部推演。
