日期：2026-10-09。当前选择：用户已授权按 HTML + CSS 导入方案修改独立原型及需规。平台和官方组件保持 Vue 3；整体原型、正式业务和 AI 接入仍待评审。本文替代同日早先以 Markdown 指令为首轮入口的提案。

## 1. 选型与职责

目标是让作者把自己或 AI 编写的一段代码快速添加成一个可移动模块，例如时间轴，不必先为每种视觉样式开发新 Vue 组件。

| 层次 | 本轮选择 | 职责与边界 |
| --- | --- | --- |
| 平台及官方组件 | Vue 3 | 问卷、编辑器、画布、保存及已有文字/步骤/问答组件 |
| 作者代码入口 | 静态 HTML + CSS | 自定义模块内部视觉结构；粘贴或读取 UTF-8 HTML 文件 |
| 模块渲染 | iframe srcdoc，空 sandbox，限制资源的 CSP | 在独立文档显示，样式不进入平台；不允许脚本、同源权限、表单、弹窗和嵌套页面 |
| 保存契约 | JSON 中的源码、规则版本和布局 | 原文可编辑；移动与缩放不重新生成代码 |
| 后续扩展 | 受控 Vue 插件、Markdown 指令、Mermaid | 尚未实施，不是本轮使用前提 |

Vue 组件仍适合开发者提供的可复用交互能力，但任意 `.vue` 文件可能涉及脚本、编译、依赖和平台接口。本轮采用静态 HTML + CSS，减少作者导入门槛和运行规则；这种代码块并不自动具有官方组件的逐项表单编辑、数据绑定或业务交互。

## 2. 作者操作

1. 在工作稿选择“导入 HTML 模块”，填写模块名称。
2. 粘贴 HTML + CSS，或读取 `.html/.htm` 文件；可使用内置时间轴示例。
3. 点击“检查并预览”，切换宽屏/窄屏查看效果。
4. 检查通过后确认添加；在画布移动、缩放或输入位置与尺寸。
5. 选中模块并“编辑 HTML + CSS”，再次检查后确认更新。
6. 保存私人草稿，再次打开继续编辑。

代码检查与实际应用分开。改源码使旧检查失效；旧预览保留并明确提示。错误或取消保留原模块；源码编辑不替换模块 ID 和布局。文件读取失败保留之前输入，不直接创建半成品。原型通过浏览器本地存储保存，不写入业务系统。

## 3. 首轮代码规范 v1

推荐输入 HTML 内容片段，样式写在片段的 `<style>` 或元素 `style` 中，不依赖完整网页外壳。HTML 文件使用同样的内容规则；不承诺完整站点导入或任意 HTML 文件还原。文档标题、字符编码和 viewport 元数据不作为模块正文；原始源码仍保留。

支持段落、标题、列表、分区、表格、语义标签、`details/summary` 折叠和 CSS 媒体查询。实际白名单由 [html-blocks.js](prototypes/topic-builder/html-blocks.js) 固定；未知标签/属性会报错。模块内链接只允许简单本地 `#id` 锚点，图片只允许内嵌 base64 PNG/JPEG/GIF/WebP/AVIF，不提供图片上传入口。

本轮拒绝脚本、事件属性、Vue 指令/自定义标签、SVG、表单、外部链接、外部图片、iframe、CSS `@import` 和 `url()`。CSS 资源检查用于快速提示，沙箱和 CSP 是额外的运行限制，不能把简单正则检查视为完整安全边界。正文只在离线模板中解析和检查，不插入宿主 DOM，不通过 `v-html` 在平台运行。

限制：单块源码最多 60,000 个 JavaScript 字符长度单位；文件最多 128 KiB、UTF-8 编码；嵌套最多 40 层、节点最多 2,000 个；每份原型工作稿最多 20 个 HTML 模块。源代码过长时拒绝，不静默截断后应用。显示高度为 120—1200px，原型未对每条 CSS 语法做静态诊断，浏览器可能忽略无效样式。

## 4. 确定性与保存契约

当前原型示例：

```json
{
  "id": "stable-block-id",
  "kind": "html",
  "title": "租房行动时间轴",
  "body": "",
  "code": {
    "rendererVersion": 1,
    "source": "<style>.route { color: #245c45; }</style><ol class=\"route\"><li>看房前</li><li>看房时</li></ol>",
    "frameHeight": 360
  },
  "layout": { "x": 3, "y": 558, "w": 90, "h": 500 }
}
```

`body` 是原型普通区块兼容字段，HTML 正文只取 `code.source`；页面区块数组的顺序是手机与目录阅读顺序。已有草稿外层版本仍为 1，新增模块有独立渲染版本，旧的普通区块仍可打开。

确定性边界：同一份源码在相同版本检查规则下生成相同 `srcdoc`，重复保存或移动不调用 AI。自然语言重新生成仍可能不同；浏览器、字体、视口和动态 CSS 也会影响最终像素。不能把这种规则称为跨环境像素完全相同。

保存保留原始源码，展示时可规范化换行、忽略非正文元数据，原文不被格式化结果覆盖。再次打开重新校验；未知渲染版本显示错误，不自行升级或用 AI 重写。正式业务需定义 JSON Schema、后端校验、版本升级和兼容/迁移策略；原型没有伪装成这些工作已经完成。

## 5. 自由画布与适配

- 桌面内容画布：位置 x、宽度 w 为百分比，y、高度 h 为 px；页面头部与目录暂不移动。允许重叠；移动不改变阅读顺序。
- 原型保护：宽度至少 20% 且不超出右边界；画布高度 120—1600px，y 为 0—10000px。手柄移动、缩放，键盘微调及输入框并存。
- 手机宽度不超过 760px，或选择手机预览：按独立阅读顺序堆叠，保留桌面坐标。普通正文恢复自然高度；HTML iframe 使用 `frameHeight`，超出内容内部滚动。
- 桌面自由画布：HTML iframe 填充模块可用内容区域；流式和手机模式：使用作者设置的显示高度。画布高度和内部显示高度是不同参数。
- 平台负责外部容器宽度和堆叠；作者通过 CSS 媒体查询等负责内部响应式。固定宽度元素可能仍需在 iframe 内滚动，不承诺自动改写代码。
- 自动测量高度、内部节点可视拖拽、图层、吸附、跨断点独立构图、完整撤销尚未提供。

## 6. 代码隔离

源码在未挂载的 HTML template 中检查，合格结果构造成完整 iframe 文档。预览和保存后展示均使用 `sandbox=""`、`referrerpolicy="no-referrer"`；不加 `allow-scripts` 或 `allow-same-origin`。

CSP 默认拒绝资源，允许内部/行内 CSS 和规定的 data 图片，明确拒绝脚本、联网请求、字体、媒体、对象、嵌套 frame 和表单提交。正式业务仍须在服务端验证来源与数据、固定版本、评估耗时/资源和配额；本轮结果只是独立原型验证，不替代正式安全验收。

## 7. 被替代建议与后续工作

早先推荐 Markdown + `remark-directive`，由 FINNS 注册 timeline/checklist 等组件；它适合简短文本驱动的标准组件，无法仅靠一个新标签实现任意视觉组件。用户当前重点是导入指定代码并添加模块，因此首轮改为 HTML + CSS。

Mermaid 可作为后续图表块；图表节点与页面上的独立模块不同。任意 `.vue` 文件导入、用户脚本、远程依赖、结构化表单与任意源码双向转换继续分轮评估。正式生产入口应在本轮原型评审后再做概要设计。
