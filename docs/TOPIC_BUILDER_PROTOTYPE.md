## 1. 本轮原型目标

让作者亲自走完“AI 沟通 → 创建问卷 → 需求确认 → AI 生成 → 可编辑预览 → 保存私人草稿”，重点评审问卷是否准确、风格选择是否具体、后续编辑是否顺畅。

原型使用 Vue 3 和 Vite，复用项目现有依赖；放在独立的 `docs/prototypes/topic-builder/`，不修改现有业务页面、接口或数据库。AI 对话与生成均为明确标注的模拟，不调用模型；浏览器草稿是演示记录，不代表服务端私人数据功能已经实现。

访问：[本机原型](http://127.0.0.1:4173/)。仅本机可访问。预览服务停止后按下方命令重新启动。

### 2026-10-09 评审调整：自由画布

### 2026-10-09 评审调整：HTML + CSS 导入

用户授权按已讨论方案修改原型和需规。编辑侧栏增加“导入 HTML 模块”，弹窗支持名称、源码、UTF-8 HTML 文件、时间轴示例、显示高度及宽/窄屏预览。检查通过后才能添加；改源码使检查失效并标记旧预览。选中已添加模块可再次编辑源码，保留 ID 和布局，错误/取消不更新原模块。

模块在独立 iframe 中显示，空 sandbox 和 CSP 限制脚本及外部资源；没有 `v-html` 宿主注入。最多 60,000 字符长度单位、128 KiB 文件、40 层嵌套、2,000 节点、20 个 HTML 模块。支持范围与数据契约以设计说明及 `html-blocks.js` 为准，没有新增 npm 依赖。

桌面自由画布 iframe 填充模块内容区域，流式/手机采用单独设置的 120—1200px 显示高度，超出部分内部滚动。平台负责外框堆叠与宽度，作者负责内部响应式 CSS；自动高度和内部节点可视编辑尚未提供。原始源码、规则版本、显示高度及布局随演示草稿保存，旧的普通区块继续可用。

| 页面/状态 | 作者可以做什么 | 原型默认方案，待确认 |
| --- | --- | --- |
| AI 创作入口 | 输入创作意图，或使用租房、看番、工具学习案例，再开始沟通 | 示例预填问卷；自定义主题需要作者补齐人群与用途，真实 AI 提取尚未接入 |
| 问卷：主题与人群 | 修改主题、目标读者、用途及预期成果 | 主题、人群、用途需要确认；允许不限定人群及自定义用途；成果可选 |
| 问卷：页面风格 | 查看四种具体说明与示意，选择风格、密度，补充偏好 | 清晰指南、问题卡片、路线时间线、学习文档；用途和风格可自由组合 |
| 问卷：资料与要求 | 粘贴资料、读取 TXT/Markdown，补充内容要求与背景 | 原型最多 16,000 字；无资料时生成明确标注的待补充结构 |
| 需求摘要 | 核对最终答案，返回修改，确认后生成 | 展示人群、用途、成果、风格、资料状态和补充要求 |
| 模拟生成 | 查看阶段进度，取消，或体验失败及重试 | 失败保留已有预览和资料；重新生成后先展示候选结果，接受才替换；已保存草稿在再次保存前保持不变 |
| 可编辑预览 | 改标题/正文，添加或删除区块，拖动排序、定位或缩放，切换区块形式与风格 | 官方文字、步骤、问题解答，加 HTML + CSS 自定义块；自由画布、手机堆叠，复杂图层仍待设计 |
| HTML 模块导入/编辑 | 粘贴或读取文件、示例起步、检查预览后应用、再次编辑原文 | 静态 HTML + CSS，未知标签/属性报错；不运行脚本或任意 Vue 文件，超出内容内部滚动 |
| 私人草稿 | 保存到当前浏览器，从侧栏再次打开，刷新后恢复保存内容 | 不公开，不写入业务系统；新建/切换有未保存提示；刷新关闭使用浏览器标准提醒，不承诺自动恢复未保存编辑 |

问卷可关闭并再次打开，在当前页面会话内保留填写答案。切换步骤回到顶部；手机使用满屏问卷，背景不滚动。重新生成时可选择保留已有预览。

## 3. 四种风格的实际差异

- 清晰指南：浅色专题头部、单栏章节与行动步骤，适中留白。
- 问题卡片：暖色专题头部、分组内容卡片；空间足够时分列，手机单列。
- 路线时间线：编号圆点与连接线突出内容顺序。
- 学习文档：中性背景、清晰目录、分隔线与较少装饰，适合反复查阅。

每种风格都能在编辑预览中切换，保留已有正文；手机预览限制页面宽度。密度有适中与紧凑两档。额外文字偏好仅记录在摘要，不伪装成已经实现的任意视觉效果。

## 4. 建议体验路径

1. 在入口选择“大学生短租”，点击“开始沟通”。
2. 修改目标人群或用途，确认问卷第一步。
3. 对照风格说明与示意，选择“问题卡片”或另一风格。
4. 使用案例资料或粘贴自己的测试文字，查看需求摘要。
5. 确认生成，编辑一段内容，调整顺序，切换阅读/手机预览。
6. 保存私人草稿，刷新，或从侧栏再次打开。
7. 可尝试看番或学习工具，判断同一套问卷能否准确表达不同意图。

代码模块体验：生成工作稿后切换自由画布 → “导入 HTML 模块” → “使用时间轴示例” → “检查并预览” → “添加到页面” → 拖动/缩放 → 左侧“编辑 HTML + CSS”并确认更新 → 保存刷新。也可读取自己准备的 UTF-8 HTML 内容片段；内部响应式通过代码编写。

底部“原型体验工具”可以模拟生成失败，用于检查重试和数据保留。它不是正式产品用户流程的一部分。
