沿用skill-creator的渐进加载原则，详细规则单独放reference；未新增全局skill副本、自动调度器、文件锁或工作区登记系统。原型确认、Plane逐项授权、Git提交/推送与部署边界不变。目录联接安装的ui-ux-pro-max不属于本轮改动。
