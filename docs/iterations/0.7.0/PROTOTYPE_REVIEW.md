## 2. 可体验入口

| 场景 | 路由 | 可操作内容 |
| --- | --- | --- |
| 内容审批 | <http://127.0.0.1:4175/admin/reviews> | 待处理/已处理/已发布/已下架；类型、作者或标题、原因、时间筛选；提交快照/旧发布版对比；通过、驳回、原因、下架与恢复 |
| 敏感规则 | <http://127.0.0.1:4175/admin/sensitive-rules> | 站长新增、修改、启停与维护记录；复审员不能访问，不回扫旧内容 |
| 作者提交片段 | <http://127.0.0.1:4175/me/submissions> | 文章/评论/专题私人草稿、检测提交、命中次数、重提、状态与原因、旧发布版、撤回/评论删除 |
| 读者预览片段 | <http://127.0.0.1:4175/review/reading> | 只按当前可见发布版展示列表/数量、标题摘要查找与阅读弹窗 |

新浏览器若未登录，先访问公开读者入口，点击右下“审核演示 · R1”→“载入审核协作样例”。该明确场景操作在虚构数据里授予一个演示审核员角色；产品默认仍只有站长有审批权，不自动建立审核员角色。演示按钮可以切换站长、作者阿远、审核员陈默、无审批权管理员和游客；全部不用真实凭据。

角色权限页已有“内容审批”独立权限，可在原有角色系统内手动调整。独立审核员只看到内容审批，不自动获得用户/角色/全站审计及敏感规则入口。站长本人的提交仍不能自审，须切换另一位已获授权的审核者。

## 3. 建议按这条路线评审

1. **快照与旧版**：载入协作样例，打开“让每次发布都更从容”。左侧是提交版v2，右侧是仍公开的v1；驳回空原因会提示，填写原因后驳回，旧版保持。工作稿后改不替换正在查看的快照。
2. **三次命中**：演示面板切到“阿远 · 作者提交”，默认选“我的新文章”。正文输入“演示拦截词”，点击检测发布：第1/2次拦截保留输入，第3次转人工。面板“重试上一次作者提交”不重复计数。修改为普通文字后可直接发布并结束本轮。
3. **审批后可见**：切站长或已授权审核员审批刚提交的文章，再进读者预览；通过前不在结果及数量中，通过后才出现。读者预览是独立数据场景，不冒充已接入真实发现/搜索/主页/收藏全链路。
4. **专题仅首次审批**：作者选择“我的新专题”，可先保存私人稿；首次发布送审，通过后再次更新普通文字直接发布。首次审批与第3次敏感命中合并为同一任务并显示两个原因。
5. **禁止自审/独立权限**：站长打开“站长的公开写作手册”，通过和驳回均禁用并解释原因；无审批权的管理员直达内容审批页被拒。取消演示审核员权限后，下一次处理同样拒绝。
6. **下架恢复**：“已发布”查看并填写原因下架；“已下架”填写原因复核指定发布版。作者保存或正常更新不能解除下架，本人不能批准恢复本人作品；恢复检测与敏感复核在同次明确操作中处理。
7. **规则与异常**：站长维护规则；演示面板可开启检测异常、保存失败、冲突、列表失败/慢加载、撤销审核权及在别处停用作者。检测失败不发布、输入和旧版保留；停用使未处理提交失效，已发布作品不自动隐藏。重新载入协作样例可恢复虚构作者使用资格及场景数据。

## 4. 演示规则及原型取舍

原型词例为“演示拦截词”“测试联系方式”（启用）和“演示推广语”（停用）。采用包含匹配示例，统一全半角/大小写并忽略空白；这是可审阅的交互样例，**不冻结生产匹配算法、正式词库或语义识别能力**。正式误报、规则内容、容量、数据迁移、接口及竞态锁须在G3/G4补齐。

数据仅在现有原型localStorage中；模拟接口统一经过既有fetch拦截、身份与CSRF演示逻辑，未连真实后端。新增作者与读者页面是F08接入片段，不是F02/F03/F06/F04等整项原型或业务已完成。普通话题、AI BUILDER私人稿、外部服务和媒体不在本次范围。
