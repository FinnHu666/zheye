# FINNS 0.7.0｜网站访问量与角色访问管理：验收清单（G7）

日期：2026-10-15。用于用户验收；“结果”列由验收时填写（通过 / 不通过 + 说明）。依据：[需规修订 5](REQUIREMENTS.md)、[实施与验证记录](IMPLEMENTATION_SITE_ACCESS.md)。

## 准备

- 测试实例：http://127.0.0.1:8090/ （全程使用 `127.0.0.1`，不要混用 `localhost`，两者 Cookie 分开，会被当成两个浏览器）。隔离 H2 库 `target/site-access-proof/h2-acceptance`，与主站 8080 和主库无关。启动：应用中 Browser 面板的 `finns-0.7-verify`，或
  `D:\java\jdk\jdk-17.0.12\bin\java.exe -jar target/finns-0.6.0.jar --server.port=8090 --server.address=127.0.0.1 --spring.datasource.url="jdbc:h2:file:./target/site-access-proof/h2-acceptance/finns;MODE=PostgreSQL;DB_CLOSE_ON_EXIT=FALSE" --finns.access.bootstrap-admin-email=demo@aitome.dev`（在项目根目录执行；程序包名仍为 0.6.0，是因为尚未发版）。
- 管理员：演示种子账户 `demo@aitome.dev`，密码见 `src/main/java/com/aitome/config/DemoData.java`（仅本地测试数据）。启动配置把它设为首位管理员。
- 第二个身份：在另一个浏览器（例如 Chrome 普通窗口 + 无痕窗口）自行注册 1–2 个测试账号，下文称“成员 A”“成员 B”。两个身份同时登录需要两个独立浏览器会话。
