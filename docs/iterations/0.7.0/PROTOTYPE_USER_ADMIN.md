## 3. 建议评审步骤

1. 打开入口，左下“用户管理演示 · R1”→“载入双管理者样例”，然后关闭面板。该场景只重置样例账号1/2/3的状态/会话与相关角色，保留已有演示作品、其他用户和记录。
2. 搜索“阿远”，体验停用：先不填原因，看行内提示；填写原因→核对影响→返回修改或确认停用。查看状态与成功说明；再按相同步骤恢复，确认“须重新登录、旧会话不恢复”。
3. 在操作记录中按“账号停用与恢复”查询，看原因、前后状态与结果。回用户页，面板勾选“下一次状态保存失败”或“下一次提交发生版本冲突”再操作，确认原因保留并需重新核对。
4. 点自己“你（站长）”的停用按钮，查看不能停用自己。面板选择“体验最后管理者保护”，此时你是有`admin.users`但无`admin.roles`的用户管理者，周以宁是唯一正常管理者；尝试停用他应被阻止。该自定义角色仅为演示既有权限组合，不是新增产品权限。
5. 面板“会话与未提交内容”→记录阿远两台旧会话→以阿远打开演示稿。重新打开面板并展开同一分组，在别处停用阿远：原文保留且提交禁用。再在别处恢复，旧会话探针仍拒绝；重新登录仍需原账号。离开时可点“丢弃演示稿并返回”。
6. “登录与密码找回”提供入口及模拟密码错误开关。停用阿远后用虚构邮箱`yuan@finns.test`体验登录提示；右下“账号演示”打开找回邮件，不发送真实邮件。恢复账号前，密码重置不能让其登录。
7. 最后可重新载入双管理者样例。真人评审重点：列表与状态是否清楚、原因和二次确认是否顺手、保护提示是否易懂、失败后是否知道如何继续。请明确确认R1及范围，或给出修改点；不能仅凭已看过页面推定G2通过。
