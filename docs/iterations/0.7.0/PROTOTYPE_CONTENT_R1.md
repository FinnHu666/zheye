## 呈现的行为（相对需规修订2）

- **保存≠发布**：保存只存私人稿（手动），提示“尚未公开/读者看到的仍是旧公开版”；发布/提交更新才先保存当前输入并冻结，再在同一次请求内检测并给结果。文章与普通话题共用同一页面与规则，仅类型不同。
- **字段规则**：草稿可缺字段；全空不创建；发布时标题/摘要/正文必填；120/280/20000按字符（码点）计，超限行内标红并阻止保存，输入保留。计数规则正式口径仍是 CT-L02（G3/G4）。
- **三个版本**并排：读者现在看到（公开版）/ 已提交待处理（冻结快照，之后修改不替换）/ 我的工作稿；复合状态“公开状态 + 工作状态”两枚徽标分开显示。
- **三级分流**复用F08修订6：无命中直接发布、低敏感发布留痕、中敏感送审、高敏感自动不通过并转人工复核（作者不见命中词）、取最高等级、无次数阈值；检测不可用或无启用规则不发布，草稿和旧公开版保留。重复提交按提交标识幂等。
- **取消送审 ≠ 撤回**：取消只作废本次提交，工作稿与旧公开版保留；撤回需二次确认弹窗，停止公开并使待审提交作废，私人保留，重新公开会重新检测。人工下架不被保存/更新/撤回解除，需另一位审批者在审批页恢复。
- **离开保护**：页面内离开弹出“保存并离开/放弃修改/继续编辑”，保存失败则不离开；同时挂浏览器原生 `beforeunload`（不承诺崩溃恢复）。点“私人预览”会先保存，保存失败不跳转。
- **安全 Markdown**：令牌树渲染，HTML/脚本只显示为文字、图片不加载（显示占位）、`javascript:` 等不安全链接不生成链接，并给作者“已按纯文本显示”的提示。
- **会话/并发**：会话过期、换号、停用时输入保留且不代存代发；多窗口版本冲突提示并允许“载入别处版本”或以自己的输入为准再保存。

## 需要用户确认的产品取舍（原型里已按推荐方案演示，非正式需规）

4. 取消送审、保存等操作不弹确认；撤回与删除草稿弹确认。
5. **删除私人草稿**：用户已确认保留（PUBLISH-D03），并回写为[需规修订3](../../requirements/FOUNDATION_CONTENT_REQUIREMENTS.md)与CT-A14/A15；原型仅允许删除**从未公开过**的私人草稿，与确认规则一致。存储语义见CT-L04（G3/G4）。
