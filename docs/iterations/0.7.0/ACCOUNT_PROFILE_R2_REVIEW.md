## 当前体验入口与步骤

- 注册入口：<http://127.0.0.1:4175/auth/register>。输入虚构邮箱；右下角“账号演示→演示收件箱”打开对应验证邮件，点击“验证邮箱并继续”，再设置昵称和密码。创建成功后前往登录。
- 资料查看：<http://127.0.0.1:4175/me>；资料编辑：<http://127.0.0.1:4175/me/profile/edit>。需要模拟登录，也可用场景控制切换阿远或站长。
- 异常：输入不完整邮箱，查看字段下错误；“场景控制→下一次资料保存失败”后保存，原内容应保留；取消时继续编辑/放弃修改；让会话失效后在原页重新登录，换账号不可保存原用户内容。
- 密码与设备/邮件均模拟，请勿输入真实凭据。只在浏览器保存演示元数据；密码不落库、不进localStorage或日志。会话失效保留内容在当前页面内存，刷新/关闭不保证恢复。
