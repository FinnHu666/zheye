| 能力 | 行为 |
| --- | --- |

## R4：专题编辑页的“可见范围”（2026-10-15，D15）

用户选择按建议在编辑页设置受限。R4 覆盖真实 `CollectionEditorPage.vue`（第 4 个 overlay 文件），并模拟工作稿、发布、预览接口：

- 编辑页左侧“专题名称”下方新增“可见范围：公开 / 受限”及说明；只有拥有“阅读受限专题”权限的作者能看到并选择受限；没有该权限、且专题也不是受限时，不显示这一项。
- 选择后随自动保存写入工作稿；已发布专题显示“点击‘更新发布’后才生效”，发布后页头出现“受限”标记。
- 作者失去权限：受限选项禁用，可改回公开（提示改回后不能再设为受限）。
- 服务端：无权限把工作稿或发布设为受限返回 403；归属检查不变（他人专题 404）。

R4 验证（本机）：构建退出码 0；管理员把公开专题 103 设为受限，自动保存后公开版本仍公开，更新发布后变为受限并显示标记；随后游客列表不含 103、总数 3、直达 401、首页专题统计 3；普通成员列表不含、直达 403；受信成员可见 200；普通成员通过接口设受限 403，编辑他人专题 404，编辑页不显示该设置；失去权限的作者可保持受限或改公开，再设受限 403，界面受限选项禁用；1280/768/390 编辑页无横向滚动。未验：真实并发编辑同一工作稿。
