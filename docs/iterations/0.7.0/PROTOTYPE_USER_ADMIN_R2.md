## 明确方向与待确认方案

用户批注已明确：**管理员不能停用管理员，增加最高优先级站长。** 这改变原修订1中“同级管理员只受自身/最后管理者保护”的边界，不能沿用旧需求批准来证明新增范围通过。

本轮向用户提出以下两项产品选择，尚未收到回答；已在评论中说明先用推荐方案制作可体验原型：

1. 站长可停用/恢复管理员、授予或撤销管理员身份；管理员只能管理普通成员，不能停用/恢复或调整其他管理员及站长。备选为站长也不直接停用管理员、仅负责角色任免。
2. 固定唯一站长，由配置指定，不在普通角色分配选项中展示；本轮账号1仅作模拟。备选为支持页面内转交站长，本轮未制作转交流程。

这两项是**待确认原型假设**。站长身份在模拟中不可降级、停用、复制或删除；所有者与普通权限矩阵分开校验，不引入任意角色优先级或继承系统。站长也不获得他人私人稿件、完整Key或本地工具访问权。后续真实初始化/配置/迁移契约尚未设计，未改真实管理员身份。

模拟接口同时阻止通过角色分配、复制管理员角色、权限修改或角色删除/用户迁移绕过这些边界，避免只禁用页面按钮。自定义角色若含管理角色权限也按管理角色保护；不改变实际业务FINNS-11。
