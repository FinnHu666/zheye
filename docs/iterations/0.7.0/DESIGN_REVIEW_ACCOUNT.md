## 外部服务与成本

- 为什么需要：需求把邮件验证/重置/通知定为必要依赖；不用外部服务就只能自建邮件服务器，对本项目成本高、送达差，不采用。
- 候选与取舍：Brevo（首选，每天 300 封）、Resend（备选，每月 3,000/每天 100）、Mailjet、SMTP2GO、Mailgun；Amazon SES 因免费期仅 6 个月且需 AWS 账号与付款方式被排除；SendGrid、Postmark、国内服务商未核实，不作依据。
- 官方来源与日期：2026-10-18 读取 resend.com/pricing、brevo.com/pricing、mailjet.com/pricing、smtp2go.com/pricing、mailgun.com/pricing、aws.amazon.com/ses/pricing（中文页）。额度会变，选定时必须在控制台再核对。
- 额度 vs 用量：邮件只由用户主动触发，预期远低于每天 80 封；风险来自被滥用耗尽，已用日预算与现有限流缓解。
- 停服/涨价/账号受限：靠 SMTP 接入，更换只改环境变量；旧域名未用链接 24 小时内过期。
- 前提与需用户提供：自有发信域名及 SPF/DKIM/DMARC；服务商账号、审批与凭据（环境变量）；服务器可达服务商的 587/465 端口；上线前用真实 QQ/163 邮箱各发一次。
