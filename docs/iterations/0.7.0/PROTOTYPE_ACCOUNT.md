## 页面与验收映射

| 页面 | 可体验行为 | 对应要求 |
| --- | --- | --- |
| `/auth/register`、`/auth/login` | 密码两次一致；新账号待验证不能登录；邮箱验证成功后正常登录 | ACCOUNT-01/08、P01 |
| `/auth/pending`、`/auth/verify` | 验证等待/成功/失效，24小时有效、60秒重发、成功重发仅最新链接有效；独立补验证保留会话 | ACCOUNT-05/06、D05 |
| `/auth/forgot`、`/auth/reset` | 统一找回提示，30分钟链接；打开不消耗；旧账号同一流程验证并重置；成功全部退出 | ACCOUNT-02/03/05、P02/06 |
| `/me/security` | 主动改密、旧密码错误/保存失败、当前设备保留/其他退出，通知失败不回滚 | ACCOUNT-04/06、P01/03/05/06 |
| `/me/security/draft` | 仅用于演示：非敏感文字内存保留，失效后原页重新登录；不同账号不得提交原内容 | P04 |
| 右下角“账号演示” | 模拟收件箱、场景切换、发送/保存/通知失败及时间快进 | ACCOUNT-06/07 |

## 建议评审顺序

1. 注册：输入虚构昵称、邮箱和8–72字符演示密码；注册后在右下角“账号演示 → 演示收件箱”打开邮件并确认。检查验证前不能登录，验证后仍需正常登录。
2. 旧账号：在“账号演示 → 场景控制”选择“载入旧账号未验证场景”。阿远仍可进入账号安全，邮箱标为待补验证。该按钮只重置阿远的验证/设备演示状态，不清空整套原型数据。
3. 找回：使用 `yuan@finns.test`，在演示收件箱打开“验证邮箱并重置密码”；检查一次完成验证与重置，成功后需重新登录。单纯打开或刷新链接不会完成修改。
4. 改密：进入账号安全，查看旧密码错误、确认不一致、保存失败及成功反馈。设备仅是模拟记录。通知失败开关不应让成功改密显示失败。
5. 内容保护：场景控制选择“体验未保存保护”，输入非敏感文字，再点击“让当前会话失效”。原文保留；换站长账号会被阻止提交，原阿远账号恢复后可继续。
6. 失效/重发：快进1分钟后重发验证/找回链接，旧链接应失效；发送失败开关保留仍有效旧链接；快进31分钟或24小时后重新打开相应邮件查看过期反馈。

登录只需对应虚构邮箱及任意非空演示密码；不会校验真实口令。原密码错误由场景开关控制。请勿输入真实凭据。
