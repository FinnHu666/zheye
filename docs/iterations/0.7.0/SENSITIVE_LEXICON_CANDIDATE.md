## 4. 疑似误报规则（修订：由“单字”改为“≤2 字符”）

导入时把长度 ≤2 个字符（中文按字、英文数字按字符）的词标为**疑似误报，默认不导入**，需显式勾选；整词匹配对中文端无效，所以短中文词只能靠不导入来避免误伤。

## 5. 导入文件格式

站长在规则页上传**一个或多个 UTF-8 文本文件**：文件名（去掉扩展名）即标签、每行一个词；也支持单个 CSV（`词语,标签`）。限制：总大小 ≤2MB、总行数 ≤20000、单词 ≤40 字。服务端不联网下载；去重按规范化后的词；同一词出现在多个类别时，**保留最高等级对应的类别**并记录其他类别。

## 6. 限制

- 本词库含政治类人名和口号等内容，仅作为站长配置的素材；是否合适、是否合法合规由站长判断。
- 规则只做关键词匹配，不识别语义；这些词库没有“语境”，命中后靠人工复核兜底。
