# FINNS-19 创建向导：C1–C4、D1、分类的子 agent 两轮讨论记录

日期：2026-10-23。**性质：用户授权“对于需求讨论的关键点，创建子agent进行两轮讨论即可，不要问我”（`/goal`），因此以下定稿由 AI 组织三位只读评审讨论后裁决，不是用户逐项回答；用户可随时否决或修改任一项。** 评审均只读（未改文件、未连数据库/Plane）。

## 评审与轮次

- P 产品/交互、B 后端架构与安全/数据（读了 `CollectionWorkspaceController`、`CollectionPublicationService`、`ReviewService`、`CollectionImportController`、`application.yml` 等）、R 交付范围与风险（读了 PLAN、ROADMAP、AI_HANDOFF）。
- 第一轮：各自独立给出 C1、C2a/b、C3、C4、D1、E 的立场与风险。第二轮：互相看到对方立场后，逐条“让步/坚持/折中”并给出最终定稿。第二轮后实质分歧仅剩 4 处，由汇总方裁决（见 §3）。

## 1. 第一轮主要分歧

封面存储（本地文件 vs 数据库 bytea；是否裁 16:9）；实现顺序与“全部目标 0.7.0”是否现实；内容模块是否建通用块模型；标签是否可点击筛选及上限；真机触屏是否必验；分类 7/8/9 项。

## 2. 第二轮收敛（已一致）

- 封面：数据库独立表 bytea（备份/迁移一致、快照引用不可变 cover_id、无路径穿越）；服务端居中裁 16:9；不做自动图像审查，下架连带隐藏、版主“仅移除封面”；封面变更不强制送人工审（站长自审会卡死，ReviewService 禁止审核本人内容）。
- multipart 全局上限现为 2MB，与原需规“≤5MB”冲突：**封面上限改为 2MB**，不抬全局（全局被导入接口共用）。
- 不建通用块模型；0.6.0 包的 `collection_entries.kind` 有 DB check 与枚举，新增 kind 会让回滚包读取失败；所有迁移只加列/加表、可空、不改约束。
- 定时发布：`scheduled_at` 列 + `@Scheduled` 每分钟轮询（`for update skip locked`，锁内复查、清空列保证幂等、不新增 status），放在“编辑进向导”之后。
- 向导里标签/分类/SEO 现存于 localStorage：编辑也进向导前必须隐藏或明示“不会保存”，避免作者误以为已保存。
- 里程碑 M0–M6（见需规）。分类取 8 项。标签上限 6。
- SEO 在纯 SPA 下对爬虫无效：M1 须由后端为 `/collections/{id}` 注入 title/meta，否则验收写明“仅改标签页标题”。
- B 的提醒：`saveDocument` 删后重插，条目 id 不稳定；导入合并有 4 处 `SaveDraftRequest` 构造须透传新字段；新文字字段要纳入 `outlineTexts` 做敏感检测；回滚冒烟须验证 0.6.0 包遇到更高版本 Flyway 记录能否启动；H2 测试是否支持 `skip locked` 需实测。

## 3. 汇总方裁决（剩余分歧）

| 分歧 | 各方 | 裁决 | 理由 |
| --- | --- | --- | --- |
| 编辑进向导属“必达”还是“开关” | P 必达；R 倾向开关 | **必达**；经典页只有在 COL-A21 回归通过后才下线 | 是用户 A1 的明确决定且是下线前提；不是可单独关闭的功能 |
| 标签点击筛选 | P/R 要可筛选；B 先只展示 | 0.7.0 **标签只展示**，数据层按“发布侧关联表+tag_norm 索引”一次做好；**点击筛选归开关集**；**分类筛选必达**；不做“标签跳标题搜索” | 筛选必须读发布版，避免泄漏；跳标题搜索语义不符（B） |
| 真机触屏 | B/P 必验；R 可“已知未验” | D1 含“发版前至少一次真机手测”；做不到须用户书面同意标为已知未验。拖拽仅验桌面鼠标，按钮排序必须可用 | 成本低、风险真实 |
| 内容模块范围 | 各不同 | 引用=插入器生成 Markdown 引用（零 schema）；卡片=章节 `layout` 列（LIST/CARDS）；时间轴=`layout` 取值，排最后；**轮播、评分榜暂缓**并从页面移除；“专题封面”并入封面上传 | 避免新块/新 kind；轮播需多图上传且无法审查；评分榜依赖暂缓的评价榜单，不手填分数 |

## 4. 与用户原决定的偏差（须用户知悉）

用户 PUBLISH-D16 选定“保留内容模块”并要求目标 0.7.0；本次定稿：①内容模块收窄为 引用/卡片/时间轴，**轮播、评分榜暂缓**；②对 0.7.0 采用“范围不变、对外开启以验收为条件”的门禁表达（见需规），并非删减范围；③封面上限由 5MB 收紧为 2MB。以上均可被用户否决。
