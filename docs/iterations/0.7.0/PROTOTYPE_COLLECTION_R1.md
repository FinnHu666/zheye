## 呈现的行为
- 保存（含自动保存约1.2秒）只改私人工作稿；发布/更新发布先保存并冻结，再在同一次请求内三级检测：无命中发布、低敏感放行留痕、中敏感送审、高敏感自动不通过转人工复核；无“首次必审”。同一提交标识重试幂等；检测不可用不发布。
- 编辑页顶部“读者现在看到 / 已提交待处理 / 我的工作稿”三版本，公开状态与工作状态两枚徽标；流转时间线；取消送审（仅中敏感待审；高敏感复核期间不提供）与撤回发布（确认弹窗，说明读者自选保留）分开；人工下架不能被保存/发布/撤回解除。
- 发布前问题列表可点击定位；失效文章引用在条目内标红说明原因，草稿可保留，发布被阻断；公开页该条只显示“原文已不可用”，不含条目标题/备注。选择器只列本人已公开文章。
- 列表：搜索、状态筛选、分页（原型每页5条）、复制内容/只用结构（新ID私人草稿，不继承任何审批）、取消送审、撤回、删除草稿（仅从未公开）、审核流转展开。导入/追加汇入私人工作稿，不自动发布。
- 撤回期间读者自选记录保留并隐藏，重发后恢复（COL-R12）；离开保护三选项；版本冲突保留输入。
