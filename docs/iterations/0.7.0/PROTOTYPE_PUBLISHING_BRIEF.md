## 目标与复用

让作者能区分保存和发布、工作稿和提交/公开版、取消送审和撤回发布。沿用Vue 3及既有`docs/prototypes/site-access`和“我的内容”/审核流转结构；制作前再核对工作树、其他写入者、路由/状态与空闲端口，必要时隔离，不默认4175空闲或服务已加载最新内容。现在不创建运行环境、不改原型代码或服务。
