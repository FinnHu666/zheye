## 2. 可体验的结果

审批队列：<http://127.0.0.1:4175/admin/reviews>。敏感规则：<http://127.0.0.1:4175/admin/sensitive-rules>。右下“审核演示 · R2”可载入“长文审阅样例”，仅重置审核演示数据并切为演示站长；已有编辑时不要载入重置。

审阅：列表“查看审批”打开 `/admin/reviews/tasks/:id`；内容处置打开 `/admin/reviews/publications/:id`。完整正文以正常网页滚动，保留段落、标题、列表、引用及代码文本，无原始 HTML 执行。首次发布仅说明没有已发布内容，不设置第二栏。有当前发布版时，按钮分别查看两份完整内容；查看旧版时禁用审批决定，需返回送审版。文末填写原因并通过/驳回，自审仍禁用。支持返回列表、刷新直达和浏览器前进后退。

敏感规则：词语/短语与备注查询、启用状态筛选、重置、每页8条；新增和编辑使用独立表单。行操作提供编辑、启停、删除。删除前显示具体词语及影响，取消保留规则，确认后从列表与后续检测中移除，历史发布内容与操作记录保留。删除采用模拟软删除；不增加回收站产品功能。写失败保留表单，过期版本阻止覆盖/删除，重复词给出提示。删除全部启用规则后检测不可用，按原规则阻止发布。规则仅站长可维护。
