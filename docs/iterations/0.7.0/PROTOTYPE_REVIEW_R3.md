## 3. 原型里已做到的

| 能力 | 原型表现 |
| --- | --- |
| 统一流程 | 文章、评论、专题同一条流水线；专题首次发布无命中直接发布；每次提交 `提交→检测→分流→（人工）→结果` |
| 低敏感 | 命中不拦截，直接发布，并进入“低敏感留痕”列表供站长事后查看 |
| 中敏感 | 第 1 次命中就送审，不再有“前2次拦截”；作者看到“待审核” |
| 高敏感 | 自动不通过、内容不公开，同时生成复核任务；作者只看到“包含不允许发布的内容”，不显示命中词；审批人在复核页选择“维持不通过”或“判定误判并放行”，两者都须原因 |
| 取最高级 | 一次命中多条规则取最高等级；标点、全半角、空白变形同样命中（与正式检测的规范化一致） |
| 作者侧时间线 | “我的发布与流转”：左侧内容列表带状态标签，右侧每次提交的时间线；审核员姓名显示为“审核员”；更早提交可展开 |
| 审批侧 | 概览卡片（中敏感待处理、高敏感复核、今日已处理、低敏感留痕）、按等级筛选、每条提交的迷你进度条；详情页顶部事实概览、整页阅读、文末决定、右侧同一条时间线（含处理人与命中详情） |
| 预留阶段 | 时间线首尾以灰色虚线占位“创建与草稿”“更新发布 · 撤回”，注明由 FINNS-18/19 提供 |
| 规则等级 | 列表带等级列与各级启用数；新增/编辑用三选一单选；可按等级筛选 |
| 词库导入预览 | （按用户批注改版）“导入词库…”弹窗按**标签批量导入**：每个标签有建议等级（政治→高，诈骗/引流→中，广告→低，可改）和导入后启用/停用；疑似误报词默认不导入；弹窗内样例检索**只读**；规则列表可**按标签批量启用/停用**；来源（houbb/sensitive-word，Apache-2.0，词库来源未核实）与规模说明仍显示 |
| 分页 | 规则列表与审批队列显示页码，支持跳转（批注①） |
| 详情 tab | 审批详情分为“内容与处理”“流转过程”两个 tab，`?tab=flow` 可直达（批注②） |
| 低敏感记录 | 列表显示摘要，可查看内容、标记已阅、下架、调整规则等级，并说明“低敏感怎么处理”（批注③） |

## 5. 限制与未做

- **未做截图**：浏览器窗口在后台，截图超时；视觉观感需用户亲自体验，未做 768px 的专项检查。
- 全部是浏览器模拟：没有真实后端/并发/持久化/权限强制；高敏感词是中性占位词，**不是真实敏感词库**；导入预览没有下载或读取任何真实词库文件，样例中的政治类词汇仅取自来源 README 的示例用于说明误报。
- 异步只表现为“时间线节点逐步出现”，检测本身仍是同步毫秒级；真异步队列已推迟到 FINNS-18/19（REVIEW-D18）。
- 创建/草稿/更新发布/撤回阶段只是占位；FINNS-18/19 接入后再点亮。
- 后端与正式前端尚未按修订6改造（当前代码仍是修订3–5版本），预览 8091 同样是旧行为。
