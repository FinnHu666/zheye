# FINNS 0.7.0｜传统专题实现设计（修订1）

日期：2026-10-23。本轮用户要求将 `http://127.0.0.1:5199/` 的更新同步项目并完成 FINNS-19，同时明确 Plane 写入无需再询问。该地址实际以 `frontend` 为 Vite root，代理到模拟接口 8099；不是另一份可整体覆盖的源码。用户实施请求确认了当前已展示的向导范围，取代旧 G2 待确认及实施待授权记录。保持 Java 17 / Spring Boot / Vue 3，版本不变，不提交、不部署、不操作主库。

## 设计

复用向导三栏、折叠、模块市场、草稿队列与会话保护。统一编辑入口，经典 URL 重定向向导；保留文件导入及复制能力。用同一阅读组件渲染私人预览、向导预览和公开页。未接入的图片轮播、评分榜、视频及 HTML 本地实验仍明示边界，不把它们算作发布内容。

在 `community_collections` 新增可空 `wizard_metadata` 文本列，存经服务端严格校验的标签、稳定分类 key、SEO、结构化适用人群及章节展示样式。保留旧 audience 与条目类型；旧请求不带 metadata 时保留原值，导入追加保持现有字段，完整复制携带创作元数据但不继承定时或审核资格。发布快照包含 metadata，公开字段来自快照，草稿修改不改变发布版。画布坐标继续作为编辑辅助，按原型明确承诺只在当前浏览器存储；公开按阅读顺序，避免未经批准改变阅读规则。

封面是不可变 UUID 图片，独立附加表，工作稿 metadata 存 coverId。先验字节数、格式、头部尺寸，再解码居中裁切16:9，最长1200，不放大，重编码JPEG清除元数据。读取逐次核对作者或当前可见发布快照，no-store/nosniff/ETag；下架隐藏，审核员仅在审核上下文读取，不能借审批权读取全部私人稿。删除无引用封面须同时核对工作稿、发布和审核快照。

定时任务保存独立冻结快照与时间，检测发生于提交时；人工审批通过后才置为可执行。到点使用锁内条件更新，仅发布冻结版，复查作者状态、权限、引用、下架和提交代次；取消、撤回、重提清除计划。保留旧有效发布版。默认开关关闭，测试实例显式开启。采用 Spring 已有调度器与数据库锁，不引入外部任务服务。

撤回保留读者自选关系、原始 published_at 和工作稿，旧审批失效；重发恢复可见。取消送审保留旧有效版，高敏感复核不可取消。物理删除只限从未公开、无待处理提交的本人 OUTLINE 草稿；事务内锁定、清理引用/导入回执与审核痕迹。引用仅允许本人文章，提交及审批最终校验有效发布状态，公开无效条目清空标题、备注、正文、ID与旧卡片信息。

SEO 由服务端在专题 HTML 入口注入转义的发布版 title/description。无阅读权或不可见时保持站点通用标题。分类筛选基于发布侧元数据，分页及总数同一过滤条件。

## 备选与能力边界

复用 D19 的数据库图片优于新增文件存储服务（无外部账号，备份一致）；冻结快照优于到点读工作稿（避免发布未检测修改）。metadata 文本附加列优于新增条目枚举（旧包可忽略字段，保留原模型）。人群保留旧文本优于覆盖迁移（不丢历史信息）。不扩大原型已声明的浏览器本地布局/HTML实验范围。

| 场景 | 能力/边界 | 处理 |
| --- | --- | --- |
| 标签 ` AI ` 与 `ai` | 归一化去重，最多6个，每个12字 | 保存时明确校验 |
| 伪装PNG、4097像素、畸形图 | 拒绝，≤2MB | 不先完整解码超大图 |
| 图片含不当内容 | 不做图像自动审查 | 作者提示、人工查看与移除；下架一起隐藏 |
| 规则为空或检测异常 | 不发布新版本 | 保留工作稿与旧版 |
| 定时期间继续改稿 | 到点只发冻结版 | 页面说明，重提才替换 |
| 50章/500条/4000字笔记上限 | 延续现有边界 | 超限400，输入保留 |
| 旧包遇新Flyway记录 | 需隔离PostgreSQL实测 | 未验前不声称可安全降级/发布 |
| 真机/触屏/多实例调度 | 本轮桌面浏览器不能证明 | 发布验收单列，调度按单实例 |

验证使用独立 H2 与隔离 PostgreSQL。无主库迁移、无生产数据删除。回退为停用新增开关、回用旧入口/旧构建；真实降级须先做备份与恢复演练。
