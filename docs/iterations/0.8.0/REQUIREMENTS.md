# FINNS 0.8.0 需求规格：自定义评价模块与租房私人验证

日期：2026-10-12。文档修订：1。目标产品版本：**0.8.0**；当前应用版本：**0.6.0**。状态：规划需规稿，未实施/发布；参数与原型尚待明确，不承诺日期。

## 1. 本版目标与依赖

将评价榜单做成可配置专题模块，租房作为第一个私人应用；通过另一个非地域、自定义类型验证扩展性。依赖 0.7.0 的管理身份/访问规则及 0.6.0 的私人专题、画布/HTML/保存基础。

功能方向来自 [已通过评审修订 3](../../requirements/FINNS-REQ-015-018_REVIEW_R3_APPROVED.md)：作者自定义实体，不只固定房源等类型；复制配置创建独立空榜单；首期私人稿验证。本次分配 0.8.0 是版本规划，未批准具体原型或业务实施。

整体分版理由见 [路线图](../../RELEASE_ROADMAP.md)；本版实现顺序见 [计划](PLAN.md)。

## 2. 使用者与流程

- 创作者管理自己的定义、对象、模块和配置快照；预设只是可改起点。
- 有资格用户只评价自己有权限访问的对象；资格不自动打开其他人的私人草稿。
- 管理员按明确权限审核和记录操作，不无痕替用户改分或读取其私人证据。

主流程：定义实体/属性/选项→添加具体对象→配置筛选/量表→提交/审核→有效统计/红黑榜→收藏/复制配置→独立空榜单；全部在明确的私人范围验证。

## 3. 自定义实体及筛选

1. 作者新增、命名、排序、停用实体类型；新增普通业务类型无需改代码，不限定为房源/租赁方/课程/工具。
2. 实体定义、具体对象和评价记录分开；对象有稳定 ID 和类型/属性，评价关联对象，不给类型标签本身计分。
3. 作者定义字段标签、必填、候选值、顺序和可筛选属性。草案支持文字/数字/单选/多选/可选地域，字段库及容量待定。
4. 对象录入表单和筛选按定义生成；未知字段、非法候选值、错误类型、缺项及跨归属修改由后端拒绝，不能只加前端标签。
5. 租房预设城市→区和全市，区必须属于城市、切换重置无效区；非地域实体可关闭此字段，用自己的分类/选择/范围。
6. 名称相同不自动合并；对象由谁录入/提报、核对/去重及个人信息边界在设计中明确，首期不默认公众目录提报。
7. 类型/字段/选项标识与显示名称分开。改名/顺序保持关联；新增字段旧对象显示缺项；停用保留历史。
8. 改字段类型、量表或计算规则须提示影响、保留定义修订，旧记录展示/是否入当前榜明确，不能无提示重解释或删除旧评价。

## 4. 评价、审核与排名

1. 量表按实体类型配置，提供总体/维度关系、分值、周期和透明排名规则；不同量表不直接混排。
2. 有提交资格的用户选择可访问对象，提交分数/文字经验/发生时期；同周期同用户/对象一条有效评价，重复请求不多票。
3. 显示待审、通过、驳回及原因；修改后的有效版本替换须明确，不能计算两版。下架/恢复/投诉记录可追溯。
4. 显示有效数、分数/分布和更新时间；缺维度不当0分，无评价显示暂无评分。
5. 红/黑榜条件、样本和时间窗可查看，样本不足不入榜，不凑榜单；中间分段仍可查看。评分不是事实/违法判定。
6. 修改/撤回/下架/恢复影响应计有效记录及榜位，分页/排序稳定；基本限速和重复保护不宣称完全杜绝刷分。
7. 私人测试参与方式需明确；不能因为管理员/登录/评分资格而读取他人稿。固定非敏感测试数据必须标明，不能冒称真人评价。
8. 不默认合同/图片服务，不公开联系人/证件/精确住户资料；对象辨识、证据可见性与纠错规则依私人边界确定。

## 5. 模块、复制及后台扩展

1. 评价模块与普通/HTML 区块并列添加、编辑、预览、收藏/导入，遵守现有画布与手机阅读顺序。
2. 模块配置、数据来源/归属、权限及展示版本分开；后台保存对象/评分，平台受控组件交互。
3. 复制类型/字段/选项/筛选/量表/展示配置，新模块/榜单/定义 ID 和当前作者归属独立；不复制对象、评分、附件、审核、旧权限。
4. 收藏是保存时配置快照，源后来变化不影响收藏/副本；副本添加对象或改配置不影响源，取消收藏不删已插入榜单。
5. 首期对象目录/评分按榜单独立，地域基础资料可复用；不增加共享实时数据或共享目录。
6. 普通新业务类型靠配置；新基础字段、特殊计算、外部连接另评审，不执行作者任意脚本/SQL/公式。
7. HTML 保留静态校验、sandbox/CSP，不获得 JS/Key/任意后台访问；原输入/文档容量不自动放宽。
8. 模块删除/撤销与后台数据保留/清理关系在设计确定，不能在规则未定时静默销毁记录。

## 6. 租房私人应用

1. 内容包括读者/场景、租前准备、找房辨识、看房清单、签约/入住/退租核对与地区经验/评价入口，具有明确使用顺序。
2. 资料来源、地区/更新时间、作者经验/事实/缺项区分；尚未提供的城市或内容不伪造为调查结果，地方规则/法律表述另核权威资料。
3. 只保存本人私人稿和预览，不在公开列表出现，不新增公开发布/分享/访客投稿；无评分也可阅读指南。
4. 复用现有编辑/画布/普通/HTML/保存恢复，不重写整个编辑器；旧内容与功能保留。
5. 内容大纲可提前准备；一并检验一个作者新定义、关闭地域的其他专题，不为每个案例另起软件版本。

## 8. 本版验收

| 验收 | 可观察条件 |
| --- | --- |
| 定义扩展 | 作者不改代码新增业务类型，配置属性/候选项并添加对象；地域关闭仍可筛选/评价 |
| 后端校验 | 非法字段/选项/类型/缺项/跨账号拒绝并保留输入，未知分数不变成0 |
| 评分闭环 | 合法提交→审核→有效统计及榜位；重复/非法/越权拒绝，修改/撤回只计有效版本 |
| 榜单显示 | 筛选/地区/量表/分页不混数据，样本不足不入榜；透明条件与无数据/失败状态 |
| 审核权限 | 普通用户不能审核/改汇总/读私证据；管理操作有原因及记录 |
| 复制/快照 | 新身份/归属、对象/评分为空；源/收藏/副本互不影响，不能引用他人私人数据 |
| 历史定义 | 改名/停用/新字段/规则变化保留关联、缺项和修订，无静默丢失或重解释 |
| 租房应用 | 方法清单和来源可辨识；私人保存/刷新/手机阅读，他人/游客拒绝，公开列表无稿 |
| 兼容/适配 | 既有账号/访问、画布/普通/HTML模块回归；桌面/390px/768px可操作 |

内部追踪：REQ-017 对应原 R01–R03；REQ-018 对应 B01–B10，数据生命周期随明确规则增加相应场景。这些标识不是产品版本。原型模拟、自动化/真实后台/真人多人证据分开，当前没有本版验收执行结果。
