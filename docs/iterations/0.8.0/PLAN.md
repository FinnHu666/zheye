# FINNS 0.8.0：自定义评价模块与租房私人验证

日期：2026-10-12。计划修订：1。目标产品版本：0.8.0。当前应用仍 0.6.0；本版仅规划，未实施/发布，不承诺日期。

## 1. 本版目标

基于 0.7.0 的基础访问管理，完成创作者自定义评价实体的私人榜单闭环：定义类型/字段/选项→添加具体对象→筛选/评分→审核/有效统计/红黑榜→复制配置为独立空榜单。

租房是首个使用案例；同时用一个非地域、自定义类型的专题证明可扩展，不将房源/租赁方写成固定允许清单。对应 [0.8.0 需规](REQUIREMENTS.md)，整体理由见 [版本路线图](../../RELEASE_ROADMAP.md)。

## 2. 范围与批次

| 工作批次 | 交付结果 | 依赖 |
| --- | --- | --- |
| A 定义与对象 | 作者配置类型/属性/选项，按定义录入对象，地域可选，前后端校验 | 本版定义/修订规则和数据归属设计 |
| B 评价与审核 | 资格校验、有效评价版本、审核原因、撤回/下架/恢复及统计 | 0.7.0 管理身份/访问边界，本版参与和量表规则 |
| C 模块与复用 | 编辑/预览/画布/手机、配置收藏、独立复制新身份/空数据 | 既有 BUILDER/HTML 边界，A/B 的稳定接口 |
| D 租房案例 | 方法目录/清单/来源及私人评价模块；非地域示例一并验证 | 实际资料/首城和模块能力；内容可提前准备 |

批次是同一产品版本内的可验证闭环，不将内部编号当成版本号，也不为每个类型重新创建一套业务模块。

## 3. 确认状态与未定项

已确认方向：自定义实体、后台扩展、配置复制建独立空榜单、私人草稿验证；租房内容与城市/区能力保留。

需在原型/设计细化：字段库/容量、定义变更和旧记录处理、量表/周期/样本/阈值、审核版本替换、对象录入/去重、私人测试参与和数据生命周期、首城/资料。现有 1–5 分及样本/阈值数字只是工作建议。

不包含公开发布/公众评分、共享目录/评分、默认合同或图片服务、任意代码插件、地图/交易/抓取。应用版本不在规划时提前修改。
