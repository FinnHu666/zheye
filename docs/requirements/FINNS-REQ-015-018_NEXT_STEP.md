## 3. 四组交互任务

### T01 首页统计

1. 展示计数、统计起点、口径说明入口。
2. 可切换正常/加载/零/未知/失败状态，失败不阻断阅读。
3. 用明确模拟事件演示“打开阅读对象计数，编辑/后台/列表请求不计”；去重窗口及首页文章弹层是否单独算一次在口径卡中展示。
4. 不模拟历史补造、真实并发准确性、机器人识别或真实访客追踪已经完成。

### T02 最小管理权限

1. 采用普通用户/管理员及“受限访问资格”的原型草案，切换用户并显示导航与无权限状态。
2. 用户列表搜索/分页、修改资格、记录变更前后值、失败保留输入；权限草案须在原型说明中明示。
3. 展示直接访问受限页面的拒绝结果，并区分访问管理与评分审核。
4. 原型角色切换是模拟，不使用真实账户，不证明 API 权限/CSRF 已实现；首个真实管理员指定方式在设计阶段处理。

### T03 租房私人专题

1. 展示租前准备、找房、看房、签约/入住/退租方法的目录和清单；缺实际资料标待补充。
2. 可以加入评价模块、在画布调整位置/尺寸、切换手机阅读预览；保留既有普通/HTML 模块入口。
3. 显示私人草稿状态，保存/刷新恢复仅标为本机模拟；无公开榜单、访客投稿或公开分享。
4. 首城未选择前使用标明的示例地区，不能用真实地名和虚构评分冒充城市调查结果。

### T04 自定义评价模块

关键流程：**新建模块 → 定义实体类型 → 定义属性与选项 → 添加具体对象 → 配置筛选/量表 → 提交与审核 → 查看榜单 → 复制到另一专题**。

1. 作者自行输入实体类型名称，增加/排序/停用类型；房源和租赁方仅为可改预设。
2. 配置字段标签、类型、必填、候选值、显示顺序和可筛选属性；地域可选，不强制非租房实体填城市/区。
3. 添加实际对象，按定义生成表单；缺项/错误类型/无效选项提示，不给类型标签本身打分。
4. 配置评分维度及可说明的排名规则，演示无数据、待审核、通过、驳回、样本不足、红/黑榜及中间分段。
5. 修改/撤回/下架/恢复展示应计有效版本变化；数据明确为测试样例，不宣传真实多人评价。
6. 复制配置后产生新模块/榜单及定义身份，目标无对象/评分，源内容不变；配置收藏是快照，源后续变化不影响收藏或副本。
7. 展示新增字段、改名、停用类型和改变量表后的历史处理提示，不静默删除旧评分。
8. 私人稿本人可见；不同模拟用户显示权限差异，多人参与方式未确定时只能演示拟议状态，不能绕过私人草稿归属。

## 4. 原型演示值与剩余细化

下列为制作原型的工作草案，界面/说明中注明，原型确认时核对；不是实际运行规则已生效。

| 项目 | 原型工作草案 | 后续核对 |
| --- | --- | --- |
| 浏览量 | 累计有效公开阅读；30 分钟同会话/对象去重的演示口径 | 页面覆盖范围、弹层阅读及统计时间 |
| 管理权限 | 两管理身份、单一受限内容访问资格 | 哪些内容受限、真实账户初始化；不扩大为复杂角色平台 |
| 字段库 | 文字、数字、单选、多选、可选地域 | 类型能力、校验/容量与字段变更处理 |
| 对象录入 | 创作者维护自己的榜单目录 | 是否需要用户提报；首期不默认共享目录 |
| 评分 | 1–5 分及量表；样本 5、红≥4、黑≤2 的透明演示参数 | 总分/维度关系、样本/周期/阈值、重评及审核替换 |
| 参与验证 | 本人私人操作 + 明确标识的角色/多评价固定样例 | 真实测试参与权限；不声称已验证真实多人投稿 |
| 租房内容 | 方法骨架、待补充资料及示例地区 | 城市和来源，不生成已核实的租房/法律建议 |

核心边界已经明确，不再将自定义实体、独立复制或私人验证列为待选择。仍需细化的项目有明确的原型/设计落点，不让下一位 AI自行扩大功能。
