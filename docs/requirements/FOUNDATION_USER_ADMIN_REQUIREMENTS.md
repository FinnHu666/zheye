## 2. 已确认产品规则

| 编号 | 行为与边界 |
| --- | --- |
| UA-R01 管理入口与权限 | 复用现有用户管理页及查询、角色筛选、分页，增加正常/停用状态、状态筛选与停用/恢复操作；沿用 `admin.users`，不新增独立停用权限。操作记录查看沿用 `admin.audit`，不得因为能管理用户而自动得到审计权限。 |
| UA-R02 操作确认与记录 | 停用与恢复都必须填写原因，去除首尾空白后不得为空，最多 200 字，并进行二次确认。可查询操作者、目标账号、前后状态、原因、时间和结果；不保存密码或恢复凭据。取消或校验失败不改变状态。 |
| UA-R03 停用 | 禁止账号登录及受保护操作，已有会话在下一次请求生效；撤销全部旧会话。保留账号、资料、角色和私人内容，不删除数据；退出仍可执行。公开内容仍按游客访问边界处理，不因停用扩大权限。 |
| UA-R04 恢复 | 恢复账号使用资格，保留现有资料与角色；必须重新登录，停用前的会话不能复活，不自动恢复登录。 |
| UA-R05 密码找回 | 停用期间仍可通过既有邮件流程重置密码，沿用 FINNS-15 的验证、限流、链接与会话规则；申请或完成重置均不能解除停用，也不能建立登录态。 |
| UA-R06 作品处置 | 停用不自动下架或隐藏已发布作品，作品维持原有可见范围。确需下架时另行操作并记录原因；恢复账号不撤销其他独立的内容处置。 |
| UA-R07 管理者保护 | 禁止操作者停用自己的账号。停用、角色调整、角色权限编辑及角色删除/迁移均必须保留至少一位正常且具有既有管理角色权限的用户；停用账号不得计入正常管理者。并发操作也不能使正常管理者归零。复用 FINNS-11 的管理者判定（`admin.roles`），不改成按角色名称判断。 |
| UA-R08 本人提示 | 只有正确密码验证后才提示“账号已停用，请联系站点管理员”；不向本人展示管理原因。错误密码与不存在账号沿用统一登录失败提示，找回密码的公开提示沿用 FINNS-15，不公开枚举账号状态。 |
| UA-R09 可靠性与内容保护 | 越权、直达/API、会话失效与 CSRF 校验保持服务端一致。状态变更失败不产生部分生效；重复操作不重复生效；发生状态冲突时要求核对，不覆盖其他管理者的新状态。停用导致会话失效时复用 FINNS-15 的未提交内容保护及换账号禁止提交规则。 |
| UA-R10 交互覆盖 | 原型及后续验收覆盖桌面、390px 手机、768px 平板、直达/刷新/前进后退、空结果、加载、失败、取消和冲突；失败保留管理原因等非敏感输入。具体页面布局仍待 G2 原型确认。 |
