### 已确认的核心范围

1. 首页显示全站累计浏览量。
2. 管理员端先采用简单访问管理，能够限制指定用户查看受限内容。
3. 首期准备租房踩坑与方法专题，先在私人草稿验证。
4. 榜单是通用专题模块，创作者可以定义评价实体类型；房源、租赁方等只是可改预设。
5. 模块及后台共同支持扩展；增加普通业务实体类型通过配置完成。
6. 复制模块只复制配置，生成独立空榜单，不携带对象/评分/权限或共享源数据。
7. 现有静态 HTML 校验和隔离展示边界保留。

### 不包含

公开发布/公开榜单/公众投稿、共享评价数据或对象目录、付费会员及复杂角色平台、任意代码插件/用户脚本、房产交易/抓取/地图、默认上传合同/图片、虚构真实评分，以及重新开发整个通用专题编辑器。

当前规划将统计/简单管理并入 0.7.0 多轮沟通版，自定义评价和租房私人验证归入 0.8.0；这是规划分配，实际日期未定，未发版或授权实施。

## 2. 使用者与主要流程

| 使用者 | 本批次能力与边界 |
| --- | --- |
| 阅读者 | 首页查看累计浏览量；阅读其有权限的既有内容 |
| 创作者 | 准备私人专题；定义评价实体及对象，配置榜单并独立复制/收藏 |
| 有评分资格的用户 | 对其被允许访问的对象提交/修改/撤回评分；私人测试参与规则见 Q08 |
| 管理员 | 管理受限访问资格及必要的审核记录；不自动取得私人草稿、Key 或本地工具权限 |

主要流程：

1. 阅读访问 → 根据确定的统计口径计数 → 首页显示持久累计值。
2. 管理员查看用户 → 修改资格 → 记录结果 → 后续访问按新资格决定。
3. 作者准备租房资料 → 创建/编辑私人专题 → 添加评价模块 → 保存与私人预览。
4. 作者定义实体类型/属性/选项 → 添加具体对象 → 配置筛选和量表 → 有资格用户提交评价 → 审核 → 有效统计及红黑榜。
5. 作者收藏/导入配置 → 生成新模块及独立空榜单 → 添加自己的对象和评价，来源保持不变。

## 3. REQ-015：首页全站累计浏览量

- **F15-01 展示**：首页显示“累计浏览量”，提供统计起点/口径说明；显示真实零、加载、未知和失败状态。
- **F15-02 含义**：指标为浏览次数，不冒称独立人数、注册人数或活跃人数；不增加逐篇文章/专题计数或热门排序。
- **F15-03 采集口径**：只累计约定的阅读行为；列表曝光、预加载、资源请求、轮询及编辑/后台是否计入应有明确规则，最终页面范围见 Q01。
- **F15-04 去重**：重复上报、短窗口刷新及重试按明确规则处理；正常访问不同阅读对象可分别计数。窗口和会话边界见 Q01。
- **F15-05 持久统计**：正式启用起累计，重启后恢复；并发更新不丢失，不凭估算补造历史浏览量。
- **F15-06 失败与基本保护**：计数失败不阻断阅读，读取失败不显示虚假 0；提供基本重复/异常请求保护，不承诺完全识别机器人或新增设备指纹。

## 4. REQ-016：简单管理员与受限内容访问

- **F16-01 最小管理身份**：明确谁可管理访问资格；普通用户不能通过注册或修改前端字段取得管理员身份。原型草案为普通用户/管理员两身份。
- **F16-02 指定用户资格**：管理员可对指定用户允许/关闭受限内容访问，页面/内容标明适用范围。简单资格模型和受限范围见 Q02，不扩大为任意角色配置器。
- **F16-03 管理操作**：用户列表支持搜索和分页；变更展示当前/目标值，失败保留输入；记录操作者、目标、时间、前后值及结果。
- **F16-04 统一授权**：导航/页面表现与后端权限一致，直达 URL 和直接请求 API 不能绕过。列表、摘要、关联条目、统计/分页、缓存及附件采用相同资源授权边界。
- **F16-05 生效与恢复**：撤销资格在后续请求生效；不自动删数据或封禁账号。登录/退出、个人资料及必要恢复入口保持可用。
- **F16-06 安全与隐私**：管理写请求验证会话、资格、目标归属/状态和 CSRF；管理身份不自动获得他人完整 AI Key、私人本地工具或私人专题。
- **F16-07 账户与职责**：首个管理员的指定和避免最后一个管理员被误移除在设计中明确；访问管理与榜单审核分别检查权限，不共用一个含糊开关。

## 5. REQ-017：首期租房私人专题

- **F17-01 内容结构**：提供读者/场景、租前准备、找房辨识、看房清单、签约/入住/退租核对与城市经验入口，具有可按顺序使用的方法和清单。
- **F17-02 资料区分**：显示资料来源、适用地区、更新时间及缺项，区分作者经验、资料事实与待补充；未知内容不由模型填成已核实结论。
- **F17-03 私人边界**：首期只保存本人草稿并私人预览，其他账号/游客不能读取；公开列表不出现该稿，不增加分享或发布入口。
- **F17-04 编辑能力复用**：沿用已有编辑、画布、手机阅读、普通/HTML 模块及保存/恢复，加入本批次评价模块；旧编辑器和既有内容不被覆盖。
- **F17-05 内容与榜单独立**：暂无评分时仍能阅读指南。首城和实际资料见 Q03；示例地区/评价明确为演示，不能当成真实调查。地方规则和法律性内容须另查权威资料再形成内容，本文不生成实际租房指导结论。

## 6. REQ-018：创作者自定义实体的通用评价模块

### 6.1 定义、具体对象与筛选

- **F18-01 实体定义**：作者可新增、命名、排序、停用实体类型。房源、租赁方、课程、工具等仅为示例，业务类型不固定在代码枚举中。
- **F18-02 属性与选项**：作者定义标签、必填、候选值、显示顺序及可筛选属性。首期字段库草案为文字、数字、单选、多选、可选地域，最终能力/容量见 Q09。
- **F18-03 具体对象**：实体定义决定“评什么”，实际对象具有独立 ID 和符合定义的属性，评价关联对象而非类型标签。名称相同不自动合并，对象录入/提报及去重规则见 Q06。
- **F18-04 配置筛选**：表单与筛选按定义生成，提供受控的搜索/选择/范围能力；类型字段使用稳定 ID，不用名称或位置作关联键。
- **F18-05 可选地域**：租房预设支持城市→区联动及全市筛选，切换城市重置无效区；其他实体可关闭地域，使用自己的分类/属性。首期不依赖自动定位或地图。
- **F18-06 后端验证**：后端按保存的定义、修订和所属榜单验证对象/评分，拒绝未知字段、非法候选值、错误类型、缺必填及跨作者修改。只在前端加标签不能作为完成证据。

### 6.2 评分、审核与榜位

- **F18-07 量表**：按实体类型配置评分维度及可说明的排序/红黑榜规则；分值、总体/维度关系、周期、样本门槛与阈值见 Q04，不执行作者任意公式或代码。
- **F18-08 提交**：有资格用户选择可访问对象，提交分数、文字经验与发生时期；每周期同一用户/对象只保留一条有效评价，重复或重试不多票。图片/合同文件服务不默认包含。
- **F18-09 审核状态**：评价具有待审/通过/驳回及原因，必要的下架/恢复/投诉可追踪；管理员不无痕修改用户分数，修改后的有效版本切换见 Q04。
- **F18-10 有效统计**：显示有效评价数、总体/维度分、分布及更新时间；缺维度不计为 0，无评价显示暂无评分；不同量表不直接混排。
- **F18-11 红黑榜**：榜位有透明条件、样本门槛与时间窗，样本不足不入榜，不强行凑满数量；保留中间分段对象查看。评分不是事实或违法认定。
- **F18-12 修改与撤回**：修改、撤回、下架、恢复反映到应计有效记录及榜位，不能重复计算新旧版本；分页和排序稳定，基本限速/重复保护不被宣传为完全防刷分。
- **F18-13 私人参与**：首期不开放公众评分；评价资格不自动赋予读取他人私人专题的权利。真实测试参与权限见 Q08，固定测试数据不得伪装真实用户评价；个人信息/证据可见性见 Q06。

### 6.3 模块复用、历史与后台扩展

- **F18-14 平台模块**：在专题中与普通/HTML 区块并列添加、编辑、预览与复用，适配自由画布和手机阅读；评分数据由后台承载，使用平台受控交互组件。
- **F18-15 独立复制**：复制实体/字段/选项/筛选/量表/展示配置，生成新模块、榜单、定义身份及当前作者归属；对象、评价、附件、审核、旧权限均不复制，目标为独立空榜单。
- **F18-16 配置收藏**：收藏保存当时配置快照；来源后续变化不影响收藏或已导入副本。副本添加对象、改配置和评分不影响来源；取消收藏不删除已插入榜单。
- **F18-17 定义修订**：改名/顺序不破坏对象和评分关联；新字段对旧对象显示缺项；停用保留历史。改字段类型、量表或计算规则须提示影响、保留修订，不能无提示用新规则重解释旧评分。
- **F18-18 扩展边界**：普通业务实体由配置新增，不为每种实体复制整套榜单；新的基础字段能力、特殊计算或外部连接另行评审。对象目录和评分按榜单独立，地域基础资料可复用。
- **F18-19 HTML 与容量**：HTML 继续静态、校验和 sandbox/CSP 隔离，不获得任意 JS/SQL/Key/后端权限。沿用已有输入/文档容量边界，不自动放宽；新增模块占用及容量见 Q09。
- **F18-20 数据生命周期**：模块、榜单和定义/评价有独立身份；模块删除、撤销、收藏取消与后台数据保留的具体关系见 Q10，不能在未定规则下静默销毁数据。

## 7. 共同要求

1. 个人资源按会话身份和资源归属校验；前端角色/作者字段不能作为后端身份来源。
2. 页面支持直达、刷新、前进后退，桌面、390px 手机和 768px 平板可操作；编辑/阅读状态明确。
3. 保存失败、冲突、输入错误保留当前内容；保存/恢复不得只依据界面提示判定持久化成功。
4. 模拟、历史证据、真实服务结果分别标识；数据未知显示未知，不补造历史统计/评分/资料。
5. 既有专题、账号隔离、私人 AI 配置、静态 HTML 与普通模块回归边界保留。
6. 保持 Java 17、Spring Boot、Vue 3/Vue Router/Vite 与 PostgreSQL 基线；本需规不选择额外 Agent 框架或插件市场，不恢复已暂缓的 REQ-008 性能项目。
